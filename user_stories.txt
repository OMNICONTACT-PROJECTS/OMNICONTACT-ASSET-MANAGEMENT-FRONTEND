****User Stories****

    As an Admin:
        I want to manage users, so I can control who has access to the system.
        I want to create and update assets, so the inventory is always up to date.
        I want to generate reports on asset usage, so I can analyze trends.

    As a Technician:
        I want to track the status of assets, so I know which assets are available or checked out.
        I want to perform audits, so I can ensure compliance with asset management policies.

    As a User:
        I want to log in securely, to access my asset requests and information.
        I want to view the assets assigned to me, so I can manage my responsibilities.

Role Model

    Fields:
        name: CharField
        permissions: ManyToManyField (to Permission model)

Permission Model

    Fields:
        name: CharField

Asset Model

    Fields:
        name: CharField
        description: TextField
        category: ForeignKey (to Category model)
        serial_number: CharField
        status: CharField (choices: available, checked out, under maintenance)
        location: CharField
        assigned_to: ForeignKey (to User model, null=True)
        created_at: DateTimeField
        updated_at: DateTimeField

Category Model

    Fields:
        name: CharField
        description: TextField

Request Model

    Fields:
        user: ForeignKey (to User model)
        asset: ForeignKey (to Asset model)
        request_date: DateTimeField
        status: CharField (choices: pending, approved, denied)
        approved_by: ForeignKey (to User model, null=True)

Audit Model

    Fields:
        asset: ForeignKey (to Asset model)
        action: CharField (choices: created, updated, deleted, checked out)
        user: ForeignKey (to User model)
        timestamp: DateTimeField

User Roles and Fields

    Admin
        Fields: All fields from User Model
        Permissions: Full access to all modules and features.

    Technician
        Fields: All fields from User Model
        Permissions: Asset tracking, auditing, and management.

    Analyst
        Fields: All fields from User Model
        Permissions: Access to reports and analytics.

    General User
        Fields: All fields from User Model
        Permissions: Request assets and view their own assigned assets.

User Capacity

    Total Number of Users: Generally can be configured based on your server capacity and licensing.
    User Fields: As outlined in the User Model.
