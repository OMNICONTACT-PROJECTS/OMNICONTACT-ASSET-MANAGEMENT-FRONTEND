****User Stories****

    As an Admin:
        I want to manage users, so I can control who has access to the system.
        I want to create and update assets, so the inventory is always up to date.
        I want to generate reports on asset usage, so I can analyze trends.

    As a Technician:
        I want to track the status of assets, so I know which assets are available or checked out.
        I want to perform audits, so I can ensure compliance with asset management policies.

    As a User:
        I want to log in securely, to access my asset requests and information.
        I want to view the assets assigned to me, so I can manage my responsibilities.

Models
User Model

    Fields:
        class User(AbstractUser):
    # exclude fields from AbstractUser
    date_joined = None
    last_login = None
    email = None

    GENDER = (
        ("MALE", "MALE"),
        ("FEMALE", "FEMALE"),
    )
    ROLE = (
        ("DEV", "DEV"),
        ("USER", "USER"),
        ("ADMIN", "ADMIN"),
        ("IS_SUPPORT", "IS_SUPPORT"),
    )
    USER_STATUS = (
        ("ACTIVE", "ACTIVE"),
        ("ON_LEAVE", "ON_LEAVE"),
        ("ON_PAUSE", "ON_PAUSE"),
        ("BUFFER", "BUFFER"),
        ("SECONDMENT", "SECONDMENT"),
        ("TERMINATED", "TERMINATED"),
    )
    ACCOUNT_STATUS = (
        ("ACTIVE", "ACTIVE"),
        ("INACTIVE", "INACTIVE"),
    )
    CONTRACT_TYPE = (
        ("FIXED", "FIXED"),
        ("MNO", "MNO"),
        ("BUFFER", "BUFFER"),
    )

    organisation = models.ForeignKey(
        Organisation, blank=True, null=True, on_delete=models.CASCADE
    )
    first_name = models.CharField(max_length=150, blank=True, null=True)
    last_name = models.CharField(max_length=150, blank=True, null=True)
    username = models.CharField(max_length=150, unique=True, blank=True, null=True)
    role = models.CharField(max_length=25, blank=True, null=True, choices=ROLE)
    gender = models.CharField(max_length=15, blank=True, null=True, choices=GENDER)
    email = models.EmailField(blank=True, null=True)
    company_email = models.EmailField(blank=True, null=True)
    phone_number = models.CharField(max_length=25, blank=True, null=True)
    national_id = models.CharField(max_length=100, blank=True, null=True)
    nationality = models.CharField(max_length=255, blank=True, null=True)
    province = models.CharField(max_length=255, blank=True, null=True)
    home_address = models.CharField(max_length=255, blank=True, null=True)
    job_title = models.CharField(max_length=150, blank=True, null=True)
    current_location = models.CharField(max_length=155, blank=True, null=True)
    department = models.ForeignKey(
        Department, blank=True, null=True, on_delete=models.CASCADE
    )
    user_status = models.CharField(
        max_length=150, blank=True, null=True, choices=USER_STATUS
    )
    account_status = models.CharField(
        max_length=150, blank=True, null=True, choices=ACCOUNT_STATUS
    )
    profile_picture = models.ImageField(
        upload_to="user_profile_pictures", blank=True, null=True
    )

    date_created = models.DateField(
        auto_now_add=True,
        blank=True,
        null=True,
        help_text="The date the employee was enrolled on the organisation's system",
    )
    last_updated = models.DateTimeField(auto_now=True, blank=True, null=True)

    USERNAME_FIELD = "username"
    EMAIL_FIELD = "email"

Asset Model
    Fields:
	organisation(fk)
        name: CharField
        description: TextField
        category: ForeignKey (to Category model)
        serial_number: CharField
        status: CharField (choices: AVAILABLE, ALLOCATED, 	UNDER_MAINTAINENCE, RESERVED, LOST, DISCARDED, TRANSFERED, 	OBSOLETE )
	value: int
        location: CharField
        allocated_to: ForeignKey (to User model, null=True)
	acquired_date: DateField
        created_at: DateTimeField
        updated_at: DateTimeField


1.2 Asset Category Model

    Table Name: AssetCategory
    Fields:
	organisation(fk)
        id (Primary Key)
        name
        description

1.3 Request Model

    Table Name: AssetRequest
    Fields:
        id (Primary Key)
	asset_requested
        category (Foreign Key referencing category)
        requested_by (Foreign Key referencing employees)
	request_date: DateField 
	approved_by: ForeignKey (to User model, null=True)(Only admin can approve)
	allocated_by: ForeignKey (to User model, null=True)
        request_status: (choices: PENDING, APPROVED, DENIED)
	allocation_status: (choices: PENDING, ALLOCATED, DENIED)
	date_approved: DateField
        created_at: DateTimeField
	updated_at: DateTimeField
	comments: TextField


1.4 Asset Allocation Model

    Table Name: AssetAllocation
    Fields:
        id (Primary Key)
        asset (Foreign Key referencing assets)
	asset_request(Foreign key)
        allocated_to (Foreign Key referencing employees)
        date_allocated: DateField
        return_date: DateField
